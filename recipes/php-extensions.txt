# The PHP extensions in Marsa's own PHP build (ADR 0012). One file for both
# readers, so they cannot drift:
#   - .github/workflows/php-build.yml (tools/php-build/build.sh and smoke.sh);
#   - `cargo xtask manifest` (xtask/src/manifest/php_smoke.rs).
#
# One extension per line: <kind> <spc name> <module name>
#   kind    builtin  always built in; spc has no name for it, so "-"
#           static   built into php and php-fpm by `spc build`
#           shared   built as a .so in the same spc run, shipped as
#                    ext/<spc name>.so, loaded with zend_extension=
#   module  what `php -m` lists (case does not matter; may contain spaces)
#
# `php -m` must list every builtin and static module, and nothing else.
